# OR-TechTask

This project takes a user-provided input and returns a concatenation of the reverse of the input, the earliest character present in the input, and "open" if the vowel count is odd or "rent" otherwise.

To run it, simply build and run the "OR-TechTask" project.

There is a set of tests to ensure the underlying methods are working as expected: to run these, build the "Or-TechTask.Tests" project before selecting "Run all tests" from the top menu (in Visual Studio).
